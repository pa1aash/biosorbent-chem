# analysis/tests/ — Unit tests for the analysis package

## What belongs here

- Tests with hand-worked expected values, especially for the hemidirection descriptor and the isotherm fitters.
- Regression tests pinning fitted parameters once a dataset is final.

## What must never go here

- Tests that assert against experimental results rather than against mathematics.
