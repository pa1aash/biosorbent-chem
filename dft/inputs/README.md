# dft/inputs/ — Quantum-chemistry input files

## What belongs here

- One input file per calculation, named for the species and job class.
- One representative input per job class is reproduced verbatim in Appendix F.

## What must never go here

- Inputs whose corresponding output was never produced or never checked for convergence.
