# analysis/ — The analysis package and its tests

## What belongs here

- `src/` — an importable Python package. `tests/` — its unit tests.
- Everything that turns `data/provided/` into `data/processed/`.

## What must never go here

- Notebooks used as the source of a reported number. Notebooks may explore; scripts produce.
- Any hard-coded experimental value.
