# data/provided/regeneration/ — Batch regeneration cycling

## What belongs here

- Three cycles x n = 3: desorption into 0.1 M HCl, and re-adsorption capacity per cycle.
- Desorbate concentrations for Pb, Cu and Zn.
- Masses adsorbed and desorbed, so desorption efficiency is recomputable.

## What must never go here

- Column regeneration data — that belongs with `column_A/` or `column_B/`.
- Capacity-retention percentages. Those are computed.
