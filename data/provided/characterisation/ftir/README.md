# data/provided/characterisation/ftir/ — ATR-FTIR spectra

## What belongs here

- Two-column CSVs: wavenumber (cm^-1) and absorbance (or transmittance, stated in the header).
- One file each for RAW-OSS, TA-OSS and spent TA-OSS, plus tannic acid if recorded.
- Acquisition parameters recorded alongside: range, resolution, number of scans, instrument model, operator.

## What must never go here

- Screenshots or images of spectra. The report re-plots every spectrum from numeric data (Bible 9.3).
- Baseline-corrected or normalised spectra without the correction being stated.
