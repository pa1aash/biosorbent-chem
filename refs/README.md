# refs/ — Bibliography and its verification record

## What belongs here

- `library.bib` — the reference database, ACS style, 35-60 entries targeted.
- `VERIFICATION_LOG.csv` — the Crossref verification record written by `scripts/verify_dois.py`.
- `pdfs/` — the PDF of every cited work.

## What must never go here

- Any entry that has not resolved against Crossref AND been confirmed read by Palaash. A single fabricated reference is an integrity finding, not a typo (Bible 13).
- Entries generated by an AI tool and not manually verified against the primary source.
