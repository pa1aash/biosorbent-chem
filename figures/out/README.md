# figures/out/ — Rendered figures consumed by LaTeX

## What belongs here

- PDF (vector) or >= 300 dpi raster output, written by the scripts in `src/`.
- Regenerated wholesale by `make figures`.

## What must never go here

- Hand-edited images. If it needs changing, change the script.
- Any file not reproducible from `src/`.
