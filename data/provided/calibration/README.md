# data/provided/calibration/ — Analytical calibration and quality control

## What belongs here

- AAS calibration curves per metal per analytical batch: standard concentrations, absorbances, fitted R^2.
- Blanks, mid-range check standards run at start/middle/end of each batch, and their recovery.
- LOD and LOQ determination data.
- Spike-recovery data.
- Every dilution factor applied to an over-range sample.

## What must never go here

- Sample results. Only the analytical QC that underwrites them.
- Curves with R^2 <= 0.99 presented as valid — the protocol rejects those batches.
