# logs/ — The AI-use record, kept in machine-readable form

## What belongs here

- `ai_use_log.csv` — one row per session: date, tool and version, session ID, project stage, specific purpose, what was done with the output, how it was verified, transcript filename.
- `sessions/` — exported transcripts.
- This directory is the evidence base for the Acknowledgement AI declaration and Appendix A. It exists so the declaration is GENERATED from an accurate record rather than reconstructed on 16 August.

## What must never go here

- Retrospective entries invented after the fact. An inaccurate declaration is worse than a thorough one.
- Gaps. Every session gets a row, including short ones.
