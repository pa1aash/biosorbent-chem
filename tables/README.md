# tables/ — Generated LaTeX tables

## What belongs here

- `src/` — one script per table. `out/` — the generated `.tex` fragments included by the report.

## What must never go here

- Tables typed by hand into a section file. Every data table is generated so that it cannot drift from the canonical numbers.
