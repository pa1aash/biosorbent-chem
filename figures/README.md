# figures/ — Every visual in the report

## What belongs here

- `src/` scripts, `out/` rendered figures, `photos/` laboratory photographs, `schemes/` chemical schemes and schematics.
- `STYLE.md` — the house style, binding on every figure. `FIGURE_REGISTER.md` — ID, caption, source, owning script, status.

## What must never go here

- A figure with no owning script in `src/` (photographs and hand-drawn schemes excepted, and those are registered too).
- Software screenshots. Everything is re-plotted (Bible 9.3).
