# data/processed/ — Script-generated derived quantities

## What belongs here

- Fitted isotherm, kinetic, thermodynamic and column-model parameters with confidence intervals.
- Derived selectivity factors, distribution coefficients, enrichment factors, capacity retentions.
- Speciation solver output and saturation indices.
- Every file here is reproducible by re-running the owning script over `data/provided/`.

## What must never go here

- Anything typed by hand. If a human wrote it, it is not processed data.
- Anything that cannot be regenerated by `make numbers`.
