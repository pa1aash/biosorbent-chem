# dft/analysis/ — Post-processing of calculation output

## What belongs here

- Energy-decomposition term tables, charge-decomposition output, deformation-density channel data.
- Thermochemical assembly: electronic energy + thermal correction + solvation + standard-state correction.
- Hemidirection descriptors computed by `analysis/src/hemidirection.py`.

## What must never go here

- Any decomposition term whose generating scheme and software are not recorded alongside it.
- Values transcribed by hand from an output file.
