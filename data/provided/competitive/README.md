# data/provided/competitive/ — Multi-metal competition data

## What belongs here

- The equal-mass ternary run (50/50/50 mg/L nominal) with MEASURED initial aliquots for all three metals.
- The minority-target ternary run (25/100/100 mg/L nominal) with measured initial aliquots.
- The RAW-OSS control run for the ternary condition.
- All three metals measured in every sample; n = 3 on headline points.

## What must never go here

- Nominal concentrations substituted for measured initial aliquots. The whole molar-ratio argument rests on the measured values.
- Computed selectivity factors — those are derived in `data/processed/`.
